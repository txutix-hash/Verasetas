VeraSetas 3.9.3 — Corrección del botón bosques OSM.

Se conserva una referencia explícita al mapa Leaflet y se utiliza para calcular el área visible. El botón informa del zoom, la carga, el éxito o el fallo. Se prueban servidores Overpass alternativos.

Sube index.html a la raíz del repositorio GitHub sustituyendo el anterior. No es necesario modificar GitHub Pages.

La consulta depende de servicios externos y no garantiza disponibilidad. Los datos forestales OSM son incompletos.
